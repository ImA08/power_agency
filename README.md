# Power. - Digital Agency Website

A modern, responsive website for Power, a digital agency specializing in designing impactful digital products. This project showcases the agency's services, portfolio, testimonials, and contact information through an elegant and interactive web interface.

## 🚀 Features

### Core Functionality
- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Interactive Navigation**: Smooth mobile hamburger menu with animated transitions
- **Testimonials Slider**: Auto-rotating customer testimonials with avatar navigation
- **Video Modal**: Integrated modal for showcasing introduction videos
- **Newsletter Subscription**: Email validation and subscription functionality
- **Scroll Spy Navigation**: Active navigation highlighting based on scroll position
- **Smooth Scrolling**: Enhanced user experience with smooth scroll animations

### Sections
- **Hero Section**: Compelling introduction with call-to-action buttons and floating design tool icons
- **Trusted By**: Showcase of major company logos (Google, Airbnb, Creative Market, Shopify, Amazon)
- **Portfolio**: Grid layout displaying digital product designs with hover effects
- **Testimonials**: Customer reviews with rotating content and avatar selection
- **Services**: Overview of agency services (UI/UX Design, Logo Branding, App Design, Website Design)
- **Newsletter**: Email subscription form for updates and project announcements
- **Footer**: Company links, social media icons, and contact information

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom properties (CSS variables), Flexbox, Grid, and modern CSS features
- **JavaScript/jQuery**: Interactive functionality and DOM manipulation
- **Google Fonts**: Nunito Sans font family for typography
- **Responsive Images**: Optimized asset management

## 🔧 Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd power_agency
   ```

2. **Open in browser**:
   - Simply open `index.html` in any modern web browser
   - No build process or server required for static files

3. **Development**:
   - Use any code editor (VS Code recommended)
   - Live server extensions can provide auto-reload functionality
